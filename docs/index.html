Elpris-LED

An LED strip that shows the day's electricity prices in color. Green when power is cheap, red when it's expensive.

An example day. The pulsing LED is right now.

Install

Connect your board to the computer with a USB cable and click the button. The page detects which chip the board has and installs the right firmware. Installing works in Chrome and Edge on a computer.

Supported boards:

  • ESP32 with 4 MB flash, e.g. ESP32 DevKit / WROOM-32 (not C3, S2 or S3). Strip data on GPIO16 (D16).
  • ESP8266 with 4 MB flash, e.g. NodeMCU or Wemos D1 mini. Strip data on GPIO2 (D4).
This browser can't install over USB. Open the page in Chrome or Edge on a computer. Installing requires the page to be opened over https.

Choose to erase the device on the first install. When updating, wifi and settings are kept as long as you don't erase.

No port to choose? Use a USB cable that carries data, not just power. On Windows and Mac the computer may need a driver for the board's USB chip, usually CP210x or CH340. On Linux, your user must be in the dialout group.

After installing

  1. The strip pulses blue and the lamp starts its own wifi called Elpris-LED-Config. Connect to it with your phone.
  2. If no page opens automatically, go to 192.168.4.1. Choose your wifi and fill in price area and number of LEDs.
  3. The lamp joins your network, fetches the prices and starts showing colors.
  4. Open http://elpris-led.local in a browser on the same network. If that doesn't work, look for elpris-led-xxxxxx in your router's device list and open its IP address. Set an OTA password and a config portal password there.

New releases are installed automatically, so you only need this page once.

Parts list, wiring diagram and source code are on GitHub. Prices come from elprisetjustnu.se.
